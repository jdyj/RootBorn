# 환경 의존 값

호스트, 포트, 주소, 계정, 저장 폴더, 글꼴·테마·맵 파일 경로처럼 실행하는 곳마다 달라질 수 있는 값에 적용한다. 코드, 테스트 도우미, `Scripts/`, `Tools/`, CI 워크플로 모두 같다.

## 원칙

1. **환경 의존 값은 코드가 아니라 데이터다.** 코드에 적으면 실행하는 곳이 바뀔 때마다 코드를 고쳐야 한다.
2. **통념은 사실이 아니다.** "개발은 localhost"처럼 흔한 짐작을 확인 없이 적지 않는다. 같은 설정 파일의 다른 키(주소, 콜백 등)에 이미 실제 호스트가 나와 있는지 먼저 본다.
3. **빠진 값은 묻거나 분명한 오류로 알린다.** 코드의 기본값으로 조용히 메우지 않는다.

## 지금 프로젝트에서

- MonoGame 판은 **실행 인자가 먼저, 다음이 환경 변수**다(`--root`/`ROOTBORN_REPO_ROOT`, `--save-root`/`ROOTBORN_SAVE_ROOT`, `--font`/`ROOTBORN_FONT`, `--ui-theme`/`ROOTBORN_UI_THEME`, `--maps`/`ROOTBORN_WORLD_MAPS` 등). 전체 표는 `game/README.md`. 새 값도 이 방식으로 더하고 그 표에 적는다.
- 기본값을 둘 때는 **어느 환경에서도 안전한 것**만 둔다(예: 저장소 안의 상대 위치, 저장소의 `output/` 아래). 사용자 세이브 폴더처럼 잘못 쓰면 데이터가 상하는 값은 기본값 없이 반드시 받는다(`--slot`이면 `--save-root`가 필요한 것처럼).
- 테스트는 임시 폴더와 고정 파일만 쓴다. 사용자 세이브 폴더(`AppData/LocalLow`)를 읽거나 쓰지 않는다.
- 접속 정보·계정 같은 비밀값은 커밋하지 않는다. 장치 접속 정보는 사용자 전역 지침에 있고 문서·로그에 개인키나 비밀번호를 쓰지 않는다.
- 환경을 더하거나(예: 멀티플레이 서버) 접속 방식을 바꿀 때는 각 환경의 실제 값을 사용자에게 확인한다.

## 리뷰 때 볼 것

```bash
git grep -nE "127\.0\.0\.1|localhost|https?://[0-9]+\.|[A-Z]:[\\/]" -- game Tools Scripts
```

걸린 것이 테스트용이거나 안전한 기본값이면 왜 안전한지 주석을 단다. 실행 경로의 값이면 인자·환경 변수로 뺀다.

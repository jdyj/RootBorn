# 다국어 규약

사용자 지시(2026-11-12): 다국어를 지원한다. Claude와 Codex 모두 따른다. MonoGame 판(`game/`) 기준이다.

## 원칙

- **언어를 더하는 일은 파일을 더하는 일이어야 한다.** 새 언어는 `game/localization/<언어 코드>.json` 하나를 더하면 된다. 코드에 언어 목록을 적지 않는다. 언어 종류를 enum이나 switch로 닫지 않는다.
- **화면과 규칙 코드에 사람이 읽는 문구를 적지 않는다.** 모든 문구는 현지화 키로 받는다(`GameText`). 데이터(JSON)의 이름·설명도 키로 둔다. 예외는 로그와 테스트 이름뿐이다.
- 지금 있는 언어: 한국어(`ko`, 기준 언어), 영어(`en`). 다른 언어는 번역 파일이 오면 더한다.

## 파일

- `data/localization/<언어>.json`: Unity 판에서 넘어온 옛 문구 표. 되도록 그대로 두고 새 문구와 고친 문구는 아래 파일에 넣는다(덮어 읽는다).
- `game/localization/<언어>.json`: MonoGame 판에서 더하거나 고친 문구. 위 파일 위에 덮어 읽는다(`GameText.LoadMerged`). 새 문구는 여기에 넣는다.
- 키 이름: `{영역}.{화면}.{요소}`(소문자, 하이픈). 예: `ui.hud.energy`, `ui.objectives.tracked`.

## 문구를 쓰는 법

- **문장을 코드에서 이어 붙이지 않는다.** 값이 들어가는 문구는 자리 표시(`{0}`, `{1}`)가 든 키 하나로 두고 `GameText.Format`을 쓴다. 언어마다 어순이 다르다. `"체력 " + value`처럼 붙이지 않는다.
- 수와 단위, 날짜와 시각도 자리 표시로 넣는다. 복수형처럼 언어마다 규칙이 다른 문구는 키를 나눈다(지금 필요한 곳이 생기면 그때 정한다).
- 키가 지금 언어에 없으면 **기준 언어(`ko`)의 문구**를 보여 주고, 기준 언어에도 없으면 키를 그대로 보여 준다. 빠진 키는 `GameText.MissingKeys`에 모인다.

## 화면이 지킬 것

- 글자 길이가 언어마다 다르다. 버튼과 줄은 글자가 길어져도 깨지지 않아야 한다: 여러 줄 글자는 줄바꿈하고, 한 줄 글자는 넘치면 줄이거나 말줄임한다. 글자 폭을 한국어 기준으로 가정해 칸 크기를 정하지 않는다.
- 줄바꿈 규칙은 `Rootborn.Ui`의 여러 줄 글자 한 곳에 둔다(공백에서 끊고, 공백 없는 문자는 글자 단위로).
- 언어를 바꾸면 열려 있는 화면의 글자가 바로 바뀐다(`GameText.LanguageChanged`).
- 글꼴은 언어가 쓰는 문자를 그릴 수 있어야 한다. 한 글꼴에 없는 문자는 다음 글꼴에서 찾는 순서(대체 글꼴 목록)를 Host의 글자 그리기 한 곳에 둔다. 글꼴 파일 경로를 화면 코드에 적지 않는다.

## 테스트

- 화면 테스트는 그 화면이 쓰는 모든 키가 **`game/localization`·`data/localization`에 있는 모든 언어**에 있는지 본다(언어 목록을 테스트에 적지 않고 폴더에서 읽는다). 문구가 정해지지 않은 키만 `KnownMissingKeys`에 이유와 함께 둔다.
- 화면마다 긴 문구(기준 문구의 2배 길이)로 바꿔도 글자가 패널 밖으로 나가지 않고 버튼이 겹치지 않는지 본다.
- 언어를 바꾼 뒤 화면의 글자가 바뀌는지 본다.

## 언어 고르기

- 실행 인자 `--lang <코드>`가 가장 먼저다. 없으면 설정에 저장된 언어, 그것도 없으면 운영체제 언어, 그 언어의 파일이 없으면 기준 언어를 쓴다.
- 설정 화면에서 언어를 바꿀 수 있게 한다(설정 값 저장이 생길 때 함께).

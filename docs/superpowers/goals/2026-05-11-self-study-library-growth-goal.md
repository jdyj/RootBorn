# Self Study Library Growth Goal Prompt

아래 프롬프트를 goal 세션에 그대로 붙여 넣고 진행한다.

```text
ROOTBORN Unity 프로젝트에서 "학생이 학교 수업을 듣지 않고 집이나 도서관에서 독학 활동을 실제 이동/상호작용으로 수행하면 집중/피로를 비용으로 사용해 스킬·특성·진로 힌트·지식이 성장하고, 하루 결과 UI와 저장/로드 후 상태에 반영되는 독학 성장 루프"를 설계/구현/검증해줘.

핵심 의도:
- 학교 수업의 대체 성장 경로를 명확히 만든다.
- 독학은 집중/피로/컨디션 관리와 스킬·지식·진로 힌트 성장을 연결한다.
- 플레이어가 학교를 나와도 자기 주도 성장 루트를 선택할 수 있어야 한다.

최우선 검증 원칙:
- 실제 플레이 방식으로 검증하지 않으면 완료로 인정하지 않는다.
- 최소 1개 이상의 PlayMode E2E는 저장 슬롯 UI, 실제 이동, 독학 장소 접근, 실제 상호작용 입력, 독학 결과, 하루 종료, 결과 UI, 저장/로드를 거쳐야 한다.
- 학교 수업/등교 루트를 수행하지 않고도 성장하는 것을 테스트로 증명해야 한다.
- 내부 API 직접 호출, 상태 강제 세팅, Transform 직접 이동으로 독학 성공을 대체하면 실패다.

절대 규칙:
- AGENTS.md와 `.claude/rules/*`를 따른다.
- `Assets/**/*.cs`는 디스크 직접 쓰기 금지. C# 신규/수정은 반드시 Unity MCP `script-update-or-create` 또는 Unity Editor 안전 경로를 사용한다.
- 모든 게임 엔티티는 100% ScriptableObject 데이터 기반이어야 한다.
- studyId, locationId, skillId, traitId, knowledgeId, careerId별 `if/switch` 분기, enum 기반 엔티티 분기, 엔티티별 C# 클래스 생성은 금지한다.
- 독학 활동, 요구 조건, 비용, 결과, 지식 해금, 진로 힌트는 SO 데이터와 전략 배열로 표현한다.
- TDD로 진행한다. 먼저 실패하는 테스트를 만들고 실패를 확인한 뒤 구현한다.
- 기존 dirty 변경 되돌리기 금지.

권장 구조:
- `SelfStudyDefinition` 또는 기존 `LifeActivityDefinition` 재사용
  - 독학 활동의 장소, 비용, 조건, 결과 전략 배열을 정의한다.
- `StudyMaterialDefinition`
  - 책, 자료, 단서, 주제 같은 독학 소재를 SO로 정의한다.
- `StudyCostEffect`
  - 집중/피로/시간 비용을 일반 전략으로 적용한다.
- `StudyProgressOutcome`
  - 스킬, 특성, 지식, 진로 힌트, 튜토리얼 단계 변화를 일반 전략으로 적용한다.
- `SelfStudyInteractor`
  - 도서관 책상, 집 책상, 게시판 등 실제 상호작용 지점을 제공한다.

목표 플레이 흐름:
1. 저장 슬롯 UI로 Town에 진입한다.
2. 플레이어가 학교 수업을 수행하지 않은 상태에서 도서관 또는 집 독학 지점으로 실제 이동한다.
3. 실제 상호작용 입력으로 독학 활동을 시작한다.
4. 독학 결과로 집중/피로/컨디션 비용이 적용된다.
5. 독학 결과로 스킬·특성·지식·진로 힌트 중 하나 이상이 증가하거나 해금된다.
6. 플레이어가 하루 종료 지점으로 실제 이동해 하루를 종료한다.
7. 하루 결과 UI에 독학 활동, 비용, 성장 결과가 표시된다.
8. 결과 UI 버튼으로 다음 날을 시작한다.
9. 저장 슬롯 UI로 같은 슬롯을 다시 로드해도 독학 결과와 컨디션/스킬/지식 상태가 유지된다.
10. 같은 독학 결과가 저장/로드 후 중복 적용되지 않는다.

멀티플레이 확장 고려:
- 독학은 개인 진행 상태로 처리한다.
- 도서관/집 독학 지점의 사용 가능 여부가 공유 월드 상태라면 데이터로 구분한다.
- 멀티플레이에서는 서버 권한으로 독학 요청을 검증하고 개인 상태만 갱신할 수 있어야 한다.

필수 테스트:
- STUDY-EDIT-001: 독학 활동 정의/자료 정의가 Registry 또는 지정 데이터 경로에서 로드된다.
- STUDY-EDIT-002: 독학 비용과 결과 전략이 엔티티 ID별 분기 없이 적용된다.
- STUDY-EDIT-003: 집중/피로 비용이 부족하면 독학이 실패하거나 명확한 비활성 상태가 된다.
- STUDY-EDIT-004: 독학 결과가 스킬/특성/지식/진로 힌트 중 하나 이상을 변경한다.
- STUDY-EDIT-005: 같은 독학 결과가 저장/로드 후 중복 적용되지 않는다.
- STUDY-E2E-001: 저장 슬롯 UI로 Town에 진입한다.
- STUDY-E2E-002: 학교 수업 없이 실제 이동으로 독학 지점에 접근한다.
- STUDY-E2E-003: 실제 상호작용 입력으로 독학을 수행한다.
- STUDY-E2E-004: 독학 결과가 UI와 도메인 상태에 함께 반영된다.
- STUDY-E2E-005: 하루 결과 UI에 독학 비용과 성장 결과가 표시된다.
- STUDY-E2E-006: 저장/로드 후 독학 결과가 유지되고 중복 적용되지 않는다.

완료 조건:
- 학교 수업 없이 독학만으로 스킬·특성·지식·진로 힌트 중 하나 이상이 성장한다.
- 독학은 집중/피로/컨디션 비용을 사용한다.
- 실제 플레이 E2E가 독학 루트를 검증한다.
- 독학 데이터는 SO와 전략 배열 기반이며 엔티티 ID별 분기가 없다.
- 관련 EditMode/PlayMode 테스트가 통과한다.
- `Scripts/ci/check-no-entity-id-branching.sh`가 통과한다.
- 최종 보고에는 수정 파일, 생성/수정한 SO 에셋, 실행한 테스트, 실제 플레이 검증 흐름, 통과/실패 결과, 멀티플레이 확장 리스크를 포함한다.
```

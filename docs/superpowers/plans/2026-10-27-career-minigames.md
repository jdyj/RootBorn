# 직업 미니게임 구현

기준은 두 2026-05-25 설계 문서다. 직업 ID 분기 없이 SO가 기억, 선택, 타이밍, 배치, 표적/회피 전략을 배열로 조합한다. Chef는 기억→타이밍, EmergencyCare는 도구 선택→순서(상위 업무에 이동 회피), Interior는 회전 가능한 가구 배치, Soldier는 표적과 장애물 회피를 사용한다. 캐릭터 이미지는 생성하지 않는다.

- [ ] 순수 세션 모델: Preview/Active/Completed/Cancelled, 유효 입력, 시간 경과, 정규화 점수. 완료 뒤 추가 입력은 거절한다. 빈/유효하지 않은 SO는 시작하지 않는다.
- [ ] Sequence: 미리 보여 준 순서를 기억, 미리보기 중 입력 거절, 오답/시간 만료 실패.
- [ ] Choice: 상황별 선택, 오답도 기록하며 다음 문제로 이동, 올바른 답의 비율로 채점.
- [ ] Timing: 정의한 박자와 허용 구간, 프레임 시간 차이와 무입력·난타를 검증.
- [ ] Placement: 격자/회전/다중 셀, 경계/겹침/출입 통로 제한, 완성 조건과 조화 보너스.
- [ ] TargetDodge: 실제 포인터 조준, 차선 이동과 시간에 따른 장애물, 대상은 훈련 표적만 사용.
- [ ] 성향/스킬 보정 SO: 판정 폭, 시간, 실수 허용, 힌트, 조화, 흔들림 완화. 저장된 기존 성장 값을 읽으며 바꾸지 않는다.
- [ ] 학생 체험/성인 업무 데이터 연결. 공용 세션 소유자가 TP·보상·숙련·퀘스트를 함께 저장하고 성공 이후 한 번만 공개한다. UI가 점수만 임의로 보내 보상 받는 경로는 제공하지 않는다.
- [ ] Modern 패널, 한/영 키, 키보드/포인터 입력, 취소/실패/재요청/저장 복구 검증.
- [ ] 네 직업을 실제 Town 시설에서 시작하고 실제 입력으로 완료하는 Game View 증거.

문서에 없는 초 단위 길이/문제 수/비용 수치는 Inspector에서 조절 가능한 초기 밸런스 데이터로 기록한다. 플레이 검증 없이 완성으로 판정하지 않는다.

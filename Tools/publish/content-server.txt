# 서버가 실제로 읽는 것(코드에서 확인, 2026-11-12):
#   - data/ 아래 *.json: GameDataLoader 가 정의(등록부·엔티티 파일)를 읽는다.
#   - game/economy.json: 데이터 폴더 옆의 game/economy.json(Rootborn.Data/EconomySettings). 서버도 GameDefinitions 를 만들 때 읽는다.

#   - game/world/*.json 과 LDtk 파일(.ldtk, .ldtkl): 같이 쓰는 집의 가구 놓기를 방이 판정하려면 집 맵의 칸을 읽는다(HouseGrids).

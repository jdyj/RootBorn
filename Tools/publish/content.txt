# 배포 폴더에 같은 상대 경로로 복사할 파일 목록. 저장소 위치(루트) 기준, 한 줄에 하나.
# 빈 줄과 # 으로 시작하는 줄은 무시한다. 글롭은 bash 방식이고 **는 하위 폴더 전부.
#
#   경로/글롭            그 파일(폴더면 안의 파일 전부)을 복사한다
#   !글롭                위에서 모인 것 중 이 글롭에 맞는 것을 뺀다 (뒤에 나온 줄이 앞의 줄을 고친다)
#   @refs 글롭           맞는 JSON 파일 안에 "Assets/....png" 로 적힌 그림 파일을 전부 더한다
#   @ldtk 글롭           맞는 .ldtk 파일과 그 레벨 파일(.ldtkl), 그 파일이 가리키는 타일셋 PNG를 더한다
#   @png  글롭           맞는 PNG 파일을 더한다 (코드에 경로가 박힌 그림이나 데이터가 가리키지 않는 그림용)
#
# 자동으로 하는 것: 더해진 PNG마다 data/atlases/<PNG 경로>.atlas.json 이 있으면 함께 복사한다.
# 항상 뺀다: .meta .unity .asset .prefab .cs (Unity 전용) — 이 목록으로 되돌릴 수 없다.
# 그림과 맵을 새로 바꿀 때는 @refs·@ldtk 줄이 가리키는 데이터와 .ldtk 만 새것이면 목록은 그대로다.

# --- 게임 데이터: 시작할 때 data/ 아래 *.json 을 전부 읽는다 ---
data/**/*.json
# 좌표표(atlases)는 쓰는 그림 몫만 자동으로 따라온다.
!data/atlases/**
# 돈 설정: 데이터 폴더 옆의 game/economy.json(통화 아이템). 정의를 만들 때 읽고 데이터 지문에도 들어간다(서버와 같은 지문).
game/economy.json
# 시간 규칙: 데이터 폴더 옆의 game/time.json(하루 시작, 취침 시각 등). 없으면 게임이 시작하지 않는다.
game/time.json

# --- 월드: 맵 목록, 상호작용 지점 ---
game/world/*.json

# --- 문구: 현지화 덮어쓰기 파일(data/localization 은 위 data 줄이 가져온다) ---
game/localization/*.json

# --- UI 테마: 테마 폴더 전부(테마 폴더 안의 그림 포함). "repo:Assets/…" 로 가리키는 PNG는 @refs가 가져온다 ---
game/themes/*/
@refs game/themes/*/theme.json

# --- 맵: LDtk 프로젝트와 타일셋 ---
@ldtk Assets/LDtk/*/*.ldtk

# --- 그림: 데이터가 가리키는 PNG 전부(가구·캐릭터·NPC·아이템·UI·미니게임·시설) ---
@refs data/**/*.json
@refs game/world/*.json
